# 邮箱验证码认证方案

## 1. 已确认方案

```text
登录方式：邮箱验证码
开发环境：Mailpit
线上 MVP：Resend 免费版
验证码状态：Redis
正式会话：PostgreSQL + 安全 Cookie
邮件发送：Port/Adapter，可替换供应商
```

## 2. 登录流程

```text
用户输入邮箱
  → 标准化邮箱
  → 检查邮箱与 IP 限流
  → 生成 6 位验证码
  → 保存验证码哈希到 Redis
  → 通过邮件适配器发送
  → 用户提交验证码
  → 校验错误次数与有效期
  → 创建或获取 User
  → 创建 Session
  → 验证码立即失效
```

## 3. 接口抽象

```ts
export interface EmailSenderPort {
  sendVerificationCode(input: {
    email: string;
    code: string;
    expiresInMinutes: number;
  }): Promise<void>;
}
```

实现：

- `MailpitEmailAdapter`：本地开发；
- `ResendEmailAdapter`：线上 MVP；
- 后续可增加 `SesEmailAdapter` 或国内服务适配器。

业务层不得直接导入 Resend SDK。

## 4. 安全规则

- 验证码为 6 位数字；
- 有效期 5 分钟；
- 60 秒后才可重新发送；
- 同一邮箱和同一 IP 分别限流；
- 最多错误 5 次，之后验证码作废；
- 只保存验证码哈希；
- 验证成功后立即删除；
- 不在日志、异常追踪和审计中保存验证码；
- 登录响应不暴露邮箱是否已注册；
- Resend API Key 仅保存在服务端环境变量；
- Refresh Token 只保存哈希，并支持轮换和撤销。

## 5. 游客绑定

MVP 支持先体验后登录：

```text
匿名 Session
  → 创建 Profile
  → 完成命盘和测评
  → 查看报告预览
  → 邮箱验证
  → 在事务中转移 Profile 所有权
  → 查看完整报告
```

绑定操作必须防止：

- 同一匿名档案重复认领；
- 已归属其他用户的档案被转移；
- 登录过程中产生孤儿档案；
- 验证失败却完成所有权迁移。

## 6. 邮件域名

生产环境使用项目域名发信，例如：

```text
noreply@example.com
security@example.com
```

上线前配置：

- SPF；
- DKIM；
- DMARC；
- 发信域名验证；
- 退信和投诉 Webhook。

## 7. 邮件模板

验证码邮件只包含：

- 登录验证码；
- 有效期；
- 非本人操作提示；
- 产品名称；
- 隐私和帮助链接。

不得在邮件中包含用户的出生资料、命盘或报告内容。
