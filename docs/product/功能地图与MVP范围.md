# 功能地图与 MVP 范围

## 1. MVP 核心流程

```text
进入首页
  → 创建游客档案
  → 填写出生信息
  → 生成基础命盘
  → 完成简版 Big Five
  → 生成交叉分析报告
  → 绑定邮箱查看和保存完整报告
  → 反馈报告准确度
  → 可选分享脱敏报告
```

## 2. MVP 包含功能

### 账户与档案

- 游客体验；
- 邮箱验证码登录；
- 游客数据绑定正式账户；
- 创建和编辑个人档案；
- 查看历史命盘和报告；
- 账号注销和数据删除入口。

### 出生信息与排盘

- 公历／农历选择；
- 出生年月日时；
- 出生地点搜索；
- 经纬度和时区处理；
- 真太阳时选项；
- 节气和子时换日规则；
- 四柱、藏干、五行、十神；
- 基础刑冲合害；
- 计算警告和置信度；
- 简单模式和专业数据结构。

### 命理规则分析

- 行动方式；
- 风险偏好；
- 社交主动性；
- 决策倾向；
- 情绪表达；
- 规则意识；
- 压力应对；
- 每个维度的正向证据、反向证据和置信度；
- 规则集版本记录。

### Big Five

- 简版问卷；
- 答题进度保存；
- 反向计分；
- 五个主维度得分；
- 答卷有效性检查；
- 测评定义和计分版本记录。

### 交叉分析报告

- 报告总览；
- 传统视角；
- 心理测评视角；
- 一致项；
- 冲突项；
- 互补项；
- 不确定项；
- 可验证问题；
- 行动建议；
- 数据完整度和综合置信度。

### 反馈与分享

- 对章节或维度评价准确性；
- 补充实际情况；
- 创建和撤销分享链接；
- 分享页面默认隐藏出生日期、时间、地点和邮箱。

### 简单运营后台

- 用户与档案查询；
- 报告和任务状态查询；
- Prompt 版本查看；
- 规则版本查看；
- 测评题库管理；
- 内容和失败任务排查；
- 管理员操作审计。

## 3. MVP 不包含

- 每日运势；
- 流年专题；
- 情侣合盘；
- AI 长对话顾问；
- 日记和人生事件；
- 社区；
- 订单、支付与会员；
- 微信登录；
- 手机号登录；
- 原生 iOS/Android App；
- 多语言；
- 模型训练。

## 4. MVP 成功指标

第一阶段重点验证：

1. 用户是否愿意完成出生资料和问卷；
2. 用户是否认为交叉分析比普通算命报告更有价值；
3. 用户是否愿意绑定邮箱保存完整报告；
4. 用户是否愿意反馈准确性；
5. 用户是否愿意主动分享报告或再次回来查看。

建议追踪：

- 首页到开始分析的转化率；
- 出生资料完成率；
- 问卷完成率；
- 报告生成成功率和耗时；
- 完整报告解锁率；
- 准确／部分准确／不准确比例；
- 分享率；
- 次日和七日回访率。

## 5. 后续阶段

### 第二阶段

- 每日记录；
- 周报、月报；
- AI 复盘；
- 人生事件时间线；
- 报告历史对比。

### 第三阶段

- 会员和单次报告付费；
- 情侣或家庭关系分析；
- 年度专题；
- 微信登录和支付；
- 更多心理测评。
